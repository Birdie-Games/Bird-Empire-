# Bird Empires

A 3D bird-nation strategy sandbox for phone, iPad and desktop browsers. Design your own bird species, raise a flag, and build an empire on a living world of rival flocks.

## Play

Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root) and play at the Pages link.

The game needs an internet connection the first time it loads, for the 3D engine (three.js) and fonts.

## Features

- Species creator: body shape, wings, tail, beak, crest, patterns, gear, and a color for every body part
- Nation creator: name, capital, motto, government, and a flag designer
- Worlds from Small to Colossal, with Pangaea, continents, many continents or archipelago maps
- Up to 60 AI rival nations that expand, trade, ally, declare war, make peace and revolt
- Cities, farms, markets, libraries, barracks and fortresses; research tree; armies of five bird unit types
- Seasons, rivers, coasts, stability, revolts, random world events
- Sandbox tools: paint territory, spawn armies, found nations, spark wars and revolts

Games save automatically in the browser every turn.
